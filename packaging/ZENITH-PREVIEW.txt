Zenith Rust Edition engine preview

Run horizon-client --version to see the installed Zenith version.
Zenith versions use independent tags such as zenith-game@0.2.0-preview.1.
The release manifest records the Horizon source revision and Minecraft protocol
the build targets. Horizon Nightlies remain a separate compatibility channel.

Install the JDK major version listed in research-lock.json. Use your own
installation of the pinned Minecraft version and its matching server JAR.
Run these commands from the extracted folder:

  ./horizon-prepare --prepare --server-jar /path/to/server.jar
  ./horizon-client

Add --minecraft-dir if your Minecraft installation uses a custom directory.
On Windows use the .exe filenames. Run horizon-prepare --help for other
supported installation layouts.

Server archives include horizon-server and horizon-engine. Prepare resources
first, then run horizon-server --help for configuration and startup commands.

These archives are for compatibility checks. The preview signing key is
generated for each run. See the workflow logs for verification.
